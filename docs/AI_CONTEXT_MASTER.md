## 🎯 Project Overview
**ModVigil** is a Reddit moderation analytics dashboard built using the **Devvit SDK (v0.12.23)**. 
- **Goal:** Capture every mod action (remove, ban, approve) and provide real-time charts, spike alerts, and weekly digests.
- **Current State:** Phase 1 (Foundation/Redis) is DONE. Phase 2 (Dashboard UI) is IN PROGRESS.

## 🛠️ Technical Stack & Constraints
- **Runtime:** Node 20 (Devvit environment).
- **Frontend:** Reddit WebView (React/Vite).
- **Backend:** Devvit Triggers & Jobs.
- **Database:** `context.redis` (No external DBs allowed).
- **Permissions:** `modMail`, `modLog`, `modContributors`, `privateMessages`, `identity`, `read`.

## 📜 Mandatory Rules
1. **No `@devvit/web/server`:** Use `Devvit.addTrigger` and `context.redis`. Named imports for triggers are incompatible.
2. **Redis Limitations:** No Redis Lists (`lPush`/`rPop`). Use **Sorted Sets** (`zAdd`/`zRange`) for time-series data.
3. **Try/Catch:** EVERY trigger, job, and handler must be wrapped in a try/catch block.
4. **SVG Only:** Charts and heatmaps must be built using pure SVG. No external UI charting libraries (D3, Chart.js, etc.).
5. **No Auto-Banning:** The app must NEVER automatically ban users.

## 📂 Repository Map
